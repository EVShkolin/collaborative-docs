# Описание проекта

Проект представляет собой фронтенд-часть для проекта **collaborative-docs**

# OpenApi

Для генерации api-клиента нужно иметь openapi-спецификацию (можно сгенерировать в backend проекте) в корне.
```
npm run api:gen
```
Путь до спецификации
и локацию генерируемого файла можно сконфигурировать в `orval.config.js`
