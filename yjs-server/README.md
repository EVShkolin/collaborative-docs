# Описание проекта

Проект представляет собой сервер, который синхронизирует состояния документов между пользователями.

# Переменные окружения

Создайте .env на основе .env.example.

### Database (PostgreSQL)

| Переменная          | Описание                    | По умолчанию | Обязательна |
|---------------------|-----------------------------|--------------|-------------|
| `POSTGRES_URL`      | Хост базы данных.           | `localhost`  | Да          |
| `POSTGRES_PORT`     | Порт PostgreSQL.            | `5432`       | Да          |
| `POSTGRES_USERNAME` | Имя пользователя БД.        | `postgres`   | Да          |
| `POSTGRES_PASSWORD` | Пароль пользователя БД.     | `postgres`   | Да          |
| `POSTGRES_DB`       | Имя базы данных приложения. | `collab_doc` | Да          |

### Security

| Переменная       | Описание                                                                                                                                                          | По умолчанию     | Обязательна |
|------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------|------------------|-------------|
| `JWT_PUBLIC_KEY` | Путь к публичному SSL-ключу (`jwt-public.pem`), используемому для проверки подписи токенов. Должен совпадать с публичным ключом в `backend/config/jwt/public.pem` | `jwt-public.pem` | Да          |

### Message broker

| Переменная                | Описание                                                                                                                                                               | По умолчанию                            | Обязательна |
|---------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------|-------------|
| `MESSENGER_TRANSPORT_DSN` | DSN-строка подключения к RabbitMQ. Формат: `amqp://USER:PASSWORD@HOST:PORT/VHOST`, где `VHOST` должен быть URL-encoded. Например, `%2f` означает виртуальный хост `/`. | `amqp://guest:guest@localhost:5672/%2f` | Да          |
