# Описание проекта

Проект представляет собой REST API для проекта **collaborative-docs**

# Миграции

### Генерация классов для миграции на основе сущностей

```
php bin/console doctrine:migrations:diff
```

### Применение миграций

```
php bin/console doctrine:migrations:migrate
```

# Security

### Сгенерировать пару ключей для jwt (в config/jwt)

```
php bin/console lexik:jwt:generate-keypair
```

# Переменные окружения

Создайте .env на основе .env.example.

### Application

| Переменная      | Описание                                                                                                                                                                                                                         | По умолчанию                | Обязательна |
|-----------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------|-------------|
| `APP_ENV`       | Окружение приложения: `dev`, `test`, `prod`. Влияет на загрузку `.env.<APP_ENV>`, поведение кэша, подробность ошибок и профайлер.                                                                                                | `dev`                       | Да          |
| `APP_SECRET`    | Секретный ключ для подписи CSRF-токенов, remember-me cookie и других криптографических операций. Значение в `.env` — **заглушка**, в production обязательно заменить. Сгенерировать: `php -r "echo bin2hex(random_bytes(16));"`. | — (нет безопасного дефолта) | Да          |
| `APP_SHARE_DIR` | Каталог для общих файлов между релизами (например, при деплое через symlink-релизы). Используется в рецептах деплоя.                                                                                                             | `var/share`                 | Нет         |
| `DEFAULT_URI`   | Базовый URI приложения. Используется консольными командами и генератором URL, когда нет HTTP-контекста (например, в `messenger:consume` или `bin/console`).                                                                      | `http://localhost`          | Нет         |

### Database (PostgreSQL)

| Переменная          | Описание                    | По умолчанию | Обязательна |
|---------------------|-----------------------------|--------------|-------------|
| `POSTGRES_URL`      | Хост базы данных.           | `localhost`  | Да          |
| `POSTGRES_PORT`     | Порт PostgreSQL.            | `5432`       | Да          |
| `POSTGRES_USERNAME` | Имя пользователя БД.        | `postgres`   | Да          |
| `POSTGRES_PASSWORD` | Пароль пользователя БД.     | `postgres`   | Да          |
| `POSTGRES_DB`       | Имя базы данных приложения. | `collab_doc` | Да          |
| `POSTGRES_VERSION`  | Версия сервера PostgreSQL.  | `17`         | Да          |

### Security

| Переменная       | Описание                                                                                    | По умолчанию                                  | Обязательна |
|------------------|---------------------------------------------------------------------------------------------|-----------------------------------------------|-------------|
| `JWT_SECRET_KEY` | Путь к приватному SSL-ключу (`private.pem`), используемому для подписи токенов авторизации. | `%kernel.project_dir%/config/jwt/private.pem` | Да          |
| `JWT_PUBLIC_KEY` | Путь к публичному SSL-ключу (`public.pem`), используемому для проверки подписи токенов.     | `%kernel.project_dir%/config/jwt/public.pem`  | Да          |
| `JWT_PASSPHRASE` | Пароль, которым зашифрован `private.pem`.                                                   | `passphrase`                                  | Да          |
